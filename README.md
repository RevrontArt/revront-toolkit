# Revront Toolkit
Open-source framework for commercial digital art for real businesses - clinics, SMEs, offices. Built from Revront Arte Digital.

## The Problem
There is no open-source library for commercial art with identity. Only generic stock. Clinics and SMEs silently depend on tools like this and have no standard.

## What it provides
- CLI to generate art templates for clinics / pymes / empresas
- React / Next.js components for digital signage
- Curated prompts and styles for health & business sectors
- MIT licensed templates for commercial use

## Roadmap - 6 months with Claude for OSS
- v1.0 with CLI, 90% test coverage, full docs
- Reach 20+ external contributors
- Release free templates for healthcare SMEs
